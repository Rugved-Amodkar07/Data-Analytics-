# Dashboard Analytics System

## Project Overview

Dashboard Analytics System is a collection of interactive dashboards developed using Microsoft Power BI to analyze different business datasets and present meaningful insights through visual reports.

The project covers sales, financial, customer, employee, and operational data.

## Dashboards

### 1. Bank Loan Analysis
- Analyzes financial loan data.
- Uses Power BI to present loan-related information and trends.

### 2. Pizza Sales Analysis
- Analyzes pizza sales data.
- Provides insights into sales performance and product trends.

### 3. Superstore Analysis
- Analyzes retail sales data.
- Includes executive KPIs, customer analytics, product performance, and shipping operations.

### 4. Employee and Customer Analysis
- Uses the Classic Models dataset.
- Includes customer, employee, office, order, product, and payment data.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV datasets

## How to View the Dashboards

1. Download or clone this repository.
2. Open the required `.pbix` file using Microsoft Power BI Desktop.
3. If prompted, update the data source path to the corresponding CSV files.
4. Explore the dashboard and its visualizations.

## Project Purpose

The objective of this project is to practice data analysis, data visualization, KPI reporting, and presenting business information through interactive Power BI dashboards.
